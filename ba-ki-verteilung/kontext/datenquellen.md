# Datenquellen Deutschland (Startliste – Zugang und aktuelle Wellen jeweils prüfen)

Diese Liste nennt Institutionen und Datensätze, keine konkreten Zahlen. Jede verwendete Zahl
wird mit Tabelle/Veröffentlichung, Abrufdatum und Definition in der jeweiligen Notiz belegt.

| Thema | Quelle | Anmerkung |
|---|---|---|
| Einkommensverteilung (Haushalte) | Sozio-oekonomisches Panel (SOEP), DIW Berlin | Panel; Mikrodaten nur mit Nutzungsvertrag, Veröffentlichungen frei |
| Einkommen und Verbrauch | Einkommens- und Verbrauchsstichprobe (EVS), Destatis | alle 5 Jahre |
| Armut / Einkommen EU-vergleichbar | EU-SILC (in DE: „Leben in Europa“), Destatis/Eurostat | |
| Vermögensverteilung | Panel on Household Finances (PHF), Deutsche Bundesbank | Befragungswellen |
| Volkswirtschaftliche Gesamtrechnung, Lohnquote | Destatis (VGR) | Definition der Lohnquote prüfen |
| Arbeitsmarkt, Substituierbarkeit von Berufen | IAB (Institut für Arbeitsmarkt- und Berufsforschung) | u. a. Studien zu Substituierbarkeitspotenzialen |
| Beschäftigung, Sozialversicherung | Bundesagentur für Arbeit (Statistik) | |
| Rentenversicherung (Beitragssatz, Finanzen) | Deutsche Rentenversicherung; Rentenversicherungsbericht der Bundesregierung | |
| Sozialbudget | BMAS (Sozialbudget) | |
| Gutachten | Sachverständigenrat zur Begutachtung der gesamtwirtschaftlichen Entwicklung (Jahresgutachten) | |
| Internationale Vergleiche | OECD, IMF, Eurostat, World Inequality Database | Methodik der WID gesondert prüfen |
| Robotereinsatz | International Federation of Robotics (IFR) | Daten teils kostenpflichtig; häufig als Sekundärzitat – Originalquelle angeben |
